Выпуск про спокойное подключение: ожидание входа через браузер больше не держит ящик пять минут.

## Исправлено
- Ожидание входа через браузер можно прервать. Если вы передумали входить или закрыли вкладку входа, ящик считался подключающимся почти пять минут, и повторное подключение того же адреса отклонялось. Теперь на этапе "Жду подтверждение" есть кнопка "Отменить ожидание": она сразу освобождает адрес, и ящик можно подключать заново. Если ожидание идёт из другого окна, та же кнопка стоит рядом с отказом
- Сообщение "этот адрес уже подключается в другом окне" переводится на язык интерфейса. Раньше оно всегда было по-русски

## Прочее
- Обновлены библиотеки: Tauri 2.11 -> 2.12, rustls 0.23.42 -> 0.23.46 и zip 8.6 -> 9.8. С ними закрыты четыре предупреждения безопасности по зависимостям
- Минимальная версия Rust для сборки из исходников - 1.94: её требуют обновлённые библиотеки
