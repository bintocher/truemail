Выпуск про одно меню на экране, честные уведомления и видимую версию программы.

## Добавлено
- Внизу боковой панели видна установленная версия: нажатие открывает страницу этого выпуска на GitHub в браузере
- Обновления зависимостей приходят запросами на слияние от Dependabot, в репозитории включены оповещения о уязвимостях

## Исправлено
- На экране остаётся только одно вспомогательное меню: правый клик по обычной папке больше не оставляет рядом ранее открытое меню, а меню «Ещё», фильтр, сортировка, выбор значка умной папки и палитра цвета аккаунта закрываются клавишей Escape и открытием другого меню
- Escape сначала закрывает открытое меню и только следующим нажатием - модальное окно
- Уведомление больше не приходит о письме многолетней давности: догрузка истории ящика, новая папка и повторная выкачка после смены UIDVALIDITY больше не выглядят приходом почты
- Прогон тестов ядра не падает на выходе из процесса при зелёных тестах

## Изменено
- Спецификации задач этого выпуска лежат в `specs/`: одно меню, уведомления о свежих письмах, версия в панели, завершение тестов ядра
