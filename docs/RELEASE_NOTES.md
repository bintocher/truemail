Выпуск про метки и загрузку старых писем.

## Добавлено
- Метки для писем: раздел в боковой панели, список меток с цветом в настройках, назначение метки из меню письма, цветной значок в списке. Правила сортировки умеют ставить метку сами
- Список писем догружает старые письма с сервера при прокрутке - порциями, с индикатором и статусом. Работает для Exchange, Gmail и обычной почты (Яндекс, Outlook и другие)
- Для каждой папки настраивается, что показывать рядом с именем: всего писем, непрочитанные или ничего
- В режиме диалогов действия применяются сразу ко всей переписке
- Список "Копия" в шапке письма раскрывается по щелчку, Esc закрывает любое всплывающее окно

## Исправлено
- Контекстное меню письма не уезжает за край окна
- Открытое письмо не исчезает из непрочитанных мгновенно
- Папки Exchange выстраиваются в то же дерево, что и на сервере
- Приглашения на встречи из Exchange показывают участников и кнопки ответа
- Шапка списка писем показывает число писем в папке вместо "4 аккаунта"
- Список писем не прыгает в начало при переключении окна и обновлении данных
- Яндекс.Почта снова догружает старые письма, повторов и застревания больше нет
- Действие над свёрнутой перепиской применяется только к ней, а не ко всем письмам с той же темой
- Правила разбора почты не срабатывают на старые письма, поднятые прокруткой
- Удаление метки больше не удаляет правило, которое её ставило
- Повторяющиеся события сохраняют свои настройки, даты исключений принимаются сервером

## Изменено
- Событие календаря настраивается щелчками, окно стало шире, аккаунт и календарь показываются текстом
- В русском интерфейсе единая терминология: "метка" вместо "тег"
