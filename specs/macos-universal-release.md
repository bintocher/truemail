# Универсальная сборка macOS

- Состояние: реализована
- Утвердил: владелец проекта (утверждение выдано заранее 2026-09-16)
- Задача: issue #65
- Обновлено: 2026-09-16
- Ревизия: 2

## Цель и результат для пользователя

Пользователь macOS получает один подписанный установочный пакет, который запускается как на компьютерах Apple Silicon, так и на компьютерах с процессором Intel. Проверка обновлений на обеих архитектурах находит один и тот же выпуск и загружает один и тот же архив приложения. Подпись, о которой идет речь в этой задаче, - подпись архива обновления `.app.tar.gz` закрытым ключом программы для встроенного механизма обновлений Tauri; подпись сертификатом разработчика Apple и заверение (notarization) у Apple в эту задачу не входят и заданием сборки не выполняются.

## Границы задачи

- Задание `macos` в `.github/workflows/release.yml`, подготовка двух целей Rust и одна сборка Tauri для цели `universal-apple-darwin`.
- Выбор файлов из `target/universal-apple-darwin/release/bundle` и загрузка существующими средствами задания.
- Формирование записей `darwin-aarch64` и `darwin-x86_64` в `latest.json` из одного архива и одной подписи.
- Проверки состава двоичного файла, набора загруженных файлов и манифеста обновлений.

## Что не входит в задачу

- Изменение ключа подписи обновлений.
- Обновление версии `tauri-cli` или шаблонов установщика.
- Разделение сборки macOS на два задания.
- Изменение адреса манифеста обновлений или схемы загрузки файлов выпуска.
- Нотариальное заверение Apple, подпись сертификатом разработчика Apple, публикация в Mac App Store и поддержка архитектур кроме `aarch64` и `x86_64`.

## Текущее поведение и доказательства

- Задание `macos` работает на `macos-latest` и вызывает `cargo tauri build --bundles app,dmg` без `--target` (`.github/workflows/release.yml:149-168`).
- Загрузка берет файлы из `target/release/bundle`, поэтому результат для другой цели найден не будет (`.github/workflows/release.yml:169-176`).
- Сборка манифеста перечисляет только ключ `darwin-aarch64`; ключа `darwin-x86_64` нет (`.github/workflows/release.yml:203-210`).
- Манифест зависит от единственного задания `macos`, что позволяет оставить обе архитектуры в одном задании (`.github/workflows/release.yml:178-183`).
- Tauri уже создает архив и подпись для обновления, а открытый ключ один для всех платформ (`apps/desktop/src-tauri/tauri.conf.json:29-32`, `apps/desktop/src-tauri/tauri.conf.json:48-53`).
- Приложение использует один адрес `latest.json` для всех систем (`apps/desktop/src-tauri/src/commands.rs:253-272`).

## Термины и состояния

- Универсальная сборка - приложение macOS, двоичный файл которого содержит части `arm64` и `x86_64`.
- Архив обновления - файл `.app.tar.gz`, созданный Tauri вместе с файлом подписи `.app.tar.gz.sig`.
- Ключ платформы - имя записи в разделе `platforms` файла `latest.json`.
- Готовая сборка - состояние, в котором универсальный пакет создан, обе архитектуры подтверждены, архив и подпись загружены, а обе записи манифеста сформированы.

## Требования

### S-001. Подготовка целей Rust

WHEN начинается задание `macos`, система SHALL до сборки установить цели `aarch64-apple-darwin` и `x86_64-apple-darwin` командой `rustup target add`, завершив задание ошибкой, если хотя бы одна цель не установлена.

### S-002. Одна универсальная сборка

WHEN обе цели Rust установлены, система SHALL выполнить в задании `macos` один вызов `cargo tauri build --target universal-apple-darwin --bundles app,dmg` с прежней версией `tauri-cli` 2.11.4.

### S-003. Проверка архитектур всех исполняемых частей пакета

WHEN универсальное приложение собрано, система SHALL подтвердить средствами macOS наличие архитектур `arm64` и `x86_64` в основном двоичном файле приложения и во всех прочих исполняемых файлах и динамических библиотеках внутри пакета `.app` (`Contents/MacOS` и `Contents/Frameworks`), завершив задание ошибкой при отсутствии любой из архитектур хотя бы в одном из них.

### S-004. Источник файлов выпуска

WHEN задание загружает файлы macOS, система SHALL выбирать `.dmg`, `.app.tar.gz` и `.app.tar.gz.sig` только из `target/universal-apple-darwin/release/bundle`, завершив задание ошибкой при отсутствии архива или его подписи.

### S-005. Два ключа одного пакета

WHEN формируется `latest.json`, система SHALL записать один и тот же адрес архива `.app.tar.gz` и одну и ту же подпись под ключами `darwin-aarch64` и `darwin-x86_64`.

### S-006. Единственность файлов выпуска macOS

IF среди файлов выпуска не найдено ровно одного `.dmg` или не найдено ровно по одному архиву `.app.tar.gz` и связанному с ним файлу `.sig`, THEN система SHALL завершить задание или формирование `latest.json` ошибкой, не выбирая файл по порядку обхода каталога.

### S-007. Сохранение существующей схемы сборки и выпуска

WHILE универсальная сборка заменяет прежнюю сборку macOS, система SHALL сохранить версию `tauri-cli` 2.11.4, ключ подписи обновления, читаемый из переменных окружения (`TAURI_SIGNING_PRIVATE_KEY`, `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`), загрузку ассетов через `gh release upload --clobber` и публикацию выпуска заданием `manifest` (`gh release edit --draft=false --latest`) без изменения этих контрактов.

### S-008. Полнота манифеста

WHEN `latest.json` готов к загрузке, система SHALL проверить наличие записей `windows-x86_64`, `linux-x86_64`, `darwin-aarch64` и `darwin-x86_64`, а также непустых полей `url` и `signature` у каждой записи.

## Интерфейсы и данные

- Команда сборки macOS получает цель `universal-apple-darwin`; остальные задания не меняются.
- Каталог результатов macOS меняется с `target/release/bundle` на `target/universal-apple-darwin/release/bundle`.
- Формат `latest.json` не меняется. В `platforms` добавляется ключ `darwin-x86_64`, значения `url` и `signature` у двух ключей macOS совпадают.
- Имена загружаемых файлов остаются именами, созданными Tauri.

## Ошибки и частичные отказы

- Ошибка установки любой цели Rust останавливает задание до сборки.
- Ошибка одной из двух частей универсального двоичного файла или любой из вложенных библиотек не должна приводить к загрузке пакета, который работает только на одной архитектуре.
- Отсутствие `.dmg`, архива обновления, подписи или неоднозначный выбор нескольких подходящих файлов останавливает задание или формирование манифеста, не выбирая файл по порядку обхода.
- Уже загруженные файлы могут остаться в черновике выпуска после ошибки, но выпуск не публикуется без полного `latest.json`.

## Совместимость, перенос данных и откат

Формат пользовательских данных и настройки приложения не меняются. Откат состоит в возврате прежней команды сборки, прежнего каталога файлов и одной записи `darwin-aarch64`; установленные цели Rust не влияют на готовое приложение.

## Скорость и потребление ресурсов

Компиляция Rust выполняется для двух архитектур, поэтому время задания macOS и объем промежуточных файлов могут приблизительно удвоиться. Скачивание пользователем не удваивается: обе архитектуры получают один универсальный архив.

## Журналы, метрики и эксплуатация

- Вывод задания показывает установленные цели, команду универсальной сборки, найденные архитектуры двоичного файла и пути загружаемых файлов.
- Формирование манифеста выводит имена файлов, выбранных для обеих записей macOS, без содержимого ключей подписи.
- Ошибка проверки называет отсутствующую цель, архитектуру, архив, подпись или ключ платформы.

## Отклоненные варианты

- Две отдельные нативные сборки и два архива. Пользователь получил бы разные файлы, а принятая схема требует один универсальный пакет.
- Два отдельных задания macOS. Это усложняет зависимости и передачу файлов, хотя универсальная цель Tauri решает задачу в одном задании.
- Выбор первого файла `.app.tar.gz` из списка. Порядок обхода не является договором и может связать манифест не с тем архивом.
- Изменение ключа подписи вместе со сборкой. Это нарушило бы обновление уже установленных версий без необходимости.
