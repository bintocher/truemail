Выпуск про правила почты, работу с отправителями и порядок в списке писем.

## Добавлено
- Правила почты с группами условий "выполнены все" и "выполнено любое", исключениями, несколькими действиями подряд, своим порядком правил и ручным прогоном по выбранным папкам
- Списки заблокированных и доверенных отправителей по адресу и по домену
- Автоочистка почты по отправителю: все письма, новые сразу, только последнее, старше заданного числа дней
- Игнорирование переписки целиком, вместе с новыми письмами цепочки
- Отмена отправки письма с обратным отсчётом; письмо переживает обрыв связи и уходит при следующем подключении
- Автоответ "нет на месте": на сервере для ящиков Exchange, в самой программе для остальных, с правилами молчания для рассылок и чужих автоответов
- Подсказка получателей по истории переписки, а не по алфавиту
- Сроки у флажка письма и отдельный список дел; заодно флажок снова ставится из окна программы
- Закрепление письма в списке
- Быстрые действия: своя кнопка с горячей клавишей, выполняющая цепочку действий

## Исправлено
- Метка на письме снова видна в списке: цвет несёт полоса у левого края строки, число меток - точки рядом с отправителем
