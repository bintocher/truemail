Выпуск про устойчивую синхронизацию, локальные тела писем и честный перевод интерфейса.

## Добавлено
- В объединённых списках и в шапке письма видно, в какой ящик оно пришло: одно письмо, попавшее в два подключённых ящика, больше не выглядит двумя неразличимыми строками
- Тела писем догружаются в фоне в пределах заданной глубины хранения, поэтому письма Gmail открываются из локальной базы, а не по сети

## Исправлено
- Обрыв связи посреди синхронизации больше не обнуляет проход по ящику: программа переподключается и повторяет прерванную работу, а при полной неудаче сообщает об ошибке вместо тихого «новых писем нет»
- Смена языка больше не переводит пользовательские данные: метку с именем «Настройки», письмо с темой «Календарь», папку ящика «Контакты»
- Смена языка сразу перерисовывает дерево папок ящика, карточки разделов настроек и списки меток

## Изменено
- Список писем Exchange собирается без скачивания сырого письма целиком: вложения качаются только когда письмо открывают
- Основной язык документации — русский, английские версии лежат рядом с добавкой `.en`
