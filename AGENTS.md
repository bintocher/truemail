# Инструкции для truemail

Все доработки веди в ветке `dev`. Сразу сохраняй каждый законченный набор изменений отдельным коммитом и отправляй в `origin/dev`. В конце работы проверяй, что локальная и удалённая ветки совпадают и рабочая копия чиста. Публикуй выпуск только по отдельной команде владельца.

## Независимая проверка кода

Для каждой доработки `truemail`, включая исправления, проводи две независимые проверки кода перед выпуском.

1. Передай один и тот же набор изменений DeepSeek через `dsh` и модели Z.ai через `claudesz`.
2. Проверь замечания по коду и исправь подтверждённые ошибки до выпуска.
3. Повторно передай итоговую версию обеим моделям. Если они найдут подтверждённые ошибки, исправь их и снова проверь итоговую версию обеими моделями.
