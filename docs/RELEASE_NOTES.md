Выпуск про два дефекта, которые видно каждый день: пропавшее нажатие по письму и обрубленные буквы в теме.

## Исправлено
- Нажатие по письму больше не пропадает: при нескольких ящиках список обновлялся прямо под курсором, и письмо не открывалось, хотя строка выделялась
- Тема и имя отправителя читаются целиком, даже если отправитель разрезал заголовок по середине буквы: вместо "Сер??еевич" снова "Сергеевич". Уже полученные письма чинятся при запуске

## Изменено
- Спецификации задач выпуска лежат в `specs/`: нажатие по письму и разрезанные заголовки
